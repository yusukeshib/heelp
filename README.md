# ppp

[Download the latest release](https://github.com/yusukeshib/ppp/releases/latest/download/ppp.dmg)

[![CI](https://github.com/yusukeshib/ppp/actions/workflows/ci.yml/badge.svg)](https://github.com/yusukeshib/ppp/actions/workflows/ci.yml)

ppp is a macOS menu bar app that lets you send selected text to an LLM with any prompt and see the result instantly in a nearby popup.

![ppp translating selected text](docs/images/ppp-main.png)

## Features

- Set up any prompt you want to send to an LLM with selected text
- Use OpenRouter (easiest, with OAuth sign-in), OpenAI, or Anthropic, with configurable models and thinking levels where supported
